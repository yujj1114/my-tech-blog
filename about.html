关于我

这里是我记录学习 AI 应用过程的地方。写博客对我来说有两个意义：把一次性踩坑变成可复用的经验，以及用写作逼自己把模糊的概念想清楚。

我正在学什么

  • 大模型 API 调用与工程化实践
  • Prompt Engineering：把意图结构化表达
  • RAG 检索增强，让模型用上私有知识
  • Agent 与工具调用，让 AI 自己动手

我的学习方式

边做边学，每学一个概念就动手写一个最小可运行的东西，再把过程写成笔记。这个博客本身就是这条路的副产品。

关于这个博客

纯静态、零依赖、双击即可打开。双主题，所有内容集中在一个配置文件里。更多实现细节可以读《第一次调用大模型 API》和《从 Prompt 到 Prompt Engineering》那两篇文章。
